# Software hecho en Guatemala

En [Wais Consultores](https://waisconsultores.com/) diseño y desarrollo productos que ayudan a los equipos a reducir el trabajo manual y entender qué pasa en su operación.

## Lo que estoy construyendo

### [Vertex ERP](https://vertexerp.app/)

Una plataforma de gestión para empresas guatemaltecas. Conecta la facturación electrónica FEL, el inventario y la contabilidad, desde la venta hasta el cierre.

### [wAIsy Control](https://vertexerp.app/waisy-control)

Un espacio de trabajo para coordinar agentes de IA y revisar sus cambios en Git desde un mismo lugar. [Descargas para macOS y Windows](https://github.com/wisegt/waisy-control-downloads/releases/latest).

**Tecnologías que uso** · TypeScript, Vue, Nuxt, PostgreSQL y Supabase.
